INSTALL THE APP / 安装应用

把帅栈
装进手机。

安装后会像普通 App 一样拥有桌面图标，并以独立窗口打开。文章页面可以缓存阅读，后台与留言需要联网。

ANDROID / EDGE / CHROME

安卓手机

  1. 用 Edge 或 Chrome 打开帅栈。
  2. 点击浏览器菜单。
  3. 选择“安装应用”或“添加到主屏幕”。
  4. 确认安装即可。
IPHONE / IPAD

苹果手机

  1. 必须使用 Safari 打开帅栈。
  2. 点击底部“分享”按钮。
  3. 选择“添加到主屏幕”。
  4. 确认名称并点击添加。
