INSTALL THE APP / 安装应用

把帅栈
装进手机。

这不需要下载安装包。安卓使用 Edge 或 Chrome，iPhone 使用 Safari，把网站添加到桌面后即可像普通 App 一样打开。

ANDROID / EDGE / CHROME

安卓手机

  1. 用 Edge 或 Chrome 打开帅栈。
  2. 点击浏览器菜单。
  3. 选择“安装应用”或“添加到主屏幕”。
  4. 确认安装即可。
IPHONE / IPAD

苹果手机

  1. 必须使用 Safari 打开帅栈。
  2. 点击底部“分享”按钮。
  3. 选择“添加到主屏幕”。
  4. 确认名称并点击添加。
暂时不安装，直接打开 ↗

如果当前浏览器不支持直接安装，请使用下方对应的浏览器菜单操作。
